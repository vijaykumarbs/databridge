# Setup guide for non-technical users

## Option A — Use it immediately (no GitHub needed)

1. Download `index.html` from this repo (click the file, then "Download raw file")
2. Double-click it on your computer — it opens in your browser and is ready to use

No install, no account, works offline.

## Option B — Host it for your team via URL

### GitHub Pages (recommended, free)

1. Create a GitHub account at github.com
2. Click "Fork" on this repo
3. Go to your fork → Settings → Pages → Source: Deploy from branch → main / root → Save
4. Visit `https://YOUR-USERNAME.github.io/REPO-NAME` after ~2 minutes

### Cloudflare Pages (no GitHub needed)

1. Sign up at pages.cloudflare.com (free)
2. Click "Upload assets" and drag in `index.html`
3. Get a URL like `databridge-abc.pages.dev`

## Sharing with clients

Send them the URL. Nothing to install on their end.
For a custom domain (e.g. import.yourcompany.com), Cloudflare Pages supports this free.
